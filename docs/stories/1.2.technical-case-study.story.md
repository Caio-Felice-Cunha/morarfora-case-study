**As a** recruiter or product engineer, **I want** to understand how MorarFora turns immigration data into inspectable decisions, **so that** I can assess the live tools without access to the private application.

1. The guided CRS and city-comparison paths remain the first experience and continue linking to the live zero-login tools.

3. Private code is represented only by labeled pseudocode; no private source, TCF corpus, unpublished content, analytics, or operational data is copied.
4. Standard demo, engineering case, source-boundary, and local-run actions are present.
5. Unit, desktop/mobile Playwright, keyboard, link-health, no-network, secret, and PII gates pass.
