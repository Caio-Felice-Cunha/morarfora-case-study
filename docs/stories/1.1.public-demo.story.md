## Story

**As a** visitor, **I want** a guided path into MorarFora's live CRS and city-comparison tools, **so that** I can test real product value without navigating the private monorepo.

2. Primary CTAs open the live CRS calculator and city comparison within two clicks.
3. The first version does not publish TCF content or private source, operations, analytics, tokens, or unpublished content.
4. Live-link health, mobile layout, keyboard navigation, and security checks pass.
5. README includes demo, case study, and honest run/source availability language.
